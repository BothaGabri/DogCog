# DogCog Project

This project is a landing page for K9 Agitation Training.

## Available CSS Selectors

The following CSS selectors are defined in `index.html`:

### Element Selectors
- `body`: Sets the global font, background gradient, and default text color.
- `h2`: Styles the main section headings with custom color and shadows.
- `ul`: Basic padding and margin for unordered lists.
- `li`: Margin spacing for list items.

### Class Selectors
- `.section-container`: The main wrapper for the content, providing centering, max-width, and styling.
- `.subtitle`: Styles the introductory text under the main heading.
- `.phase`: A container for training phases with a distinct border and padding.
- `.key-point`: Highlights important goals or tips with a light background and italic text.
- `.warning`: Styling for critical safety or ethics notes with a red emphasis.
- `.highlight`: Accents specific words or phrases with a gold color and bold weight.
- `.footer-note`: Styles the concluding remarks at the bottom of the section.

### Combinator / Contextual Selectors
- `.phase h3`: Specific styling for headings within a training phase.
- `.phase p`: Line-height and color adjustments for paragraphs inside phases.
- `.phase ul`: Adjustments for lists inside phases.
